# Tool reference

_Generated by `scripts/gen_tool_docs.py` from the server's live schemas._

## `server_info`

Show SheetMCP's configuration: allowed folders, read-only mode, row limits, supported formats and usage tips.

_read-only: True, destructive: False_

## `list_files`

List spreadsheet/data files (xlsx, xlsm, csv, tsv, parquet, json/jsonl) in a folder, with size, date and sheet names.

_read-only: True, destructive: False_

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `path` | string |  | `'.'` | Folder to scan, relative to the root. |
| `recursive` | boolean |  | `True` | Include subfolders. |
| `pattern` | string \| null |  | `None` | Filename glob, e.g. '*.xlsx' or 'sales_*'. |
| `limit` | integer |  | `500` | Max files to list. |

## `describe`

Understand a file before working with it: sheets, dimensions, Excel tables, named ranges, merged cells,
formula counts, charts, and per-column inferred types with a data preview. Works for xlsx/csv/parquet/json.

_read-only: True, destructive: False_

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `path` | string | yes |  | File path, relative to the root folder (or absolute inside it). |
| `sheet` | string \| null |  | `None` | Sheet name (or 0-based index). Default: first sheet. |
| `preview_rows` | integer |  | `5` | Sample rows to include per sheet (0-50). |
| `header_row` | integer \| null |  | `None` | Row number of the header if it is not the first non-empty row. |

## `read_range`

Read cells from an xlsx/csv sheet. Returns a grid of VALUES plus a map of FORMULAS for formula cells,
so you see both what Excel shows and how it was computed. Paged: follow next_offset when truncated.

_read-only: True, destructive: False_

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `path` | string | yes |  | File path, relative to the root folder (or absolute inside it). |
| `sheet` | string \| null |  | `None` | Sheet name (or 0-based index). Default: first sheet. |
| `range` | string \| null |  | `None` | A1 range like 'A1:F50', 'B:D', '5:20'. Default: the used range. |
| `include_formulas` | boolean |  | `True` | Also return formulas ({cell: '=...'}) next to values. |
| `evaluate` | `auto` / `always` / `never` |  | `'auto'` | auto: compute formulas that have no cached value (e.g. files saved by scripts); always: recompute all; never: raw cached values. |
| `offset` | integer |  | `0` | Skip this many rows from the start of the range (paging). |
| `limit` | integer \| null |  | `None` | Max rows to return (default from server config, usually 100). |
| `format` | `json` / `markdown` |  | `'json'` | json grid or a markdown table. |

## `write_range`

Write values and formulas into an xlsx (or csv). Only cell values change; existing formatting, other
formulas, charts and sheets are preserved. A backup of the old file is made automatically.

_read-only: False, destructive: False_

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `path` | string | yes |  | File path, relative to the root folder (or absolute inside it). |
| `sheet` | string \| null |  | `None` | Sheet name (or 0-based index). Default: first sheet. |
| `start_cell` | string |  | `'A1'` | Top-left cell for `values`. |
| `values` | list[list[any]] \| null |  | `None` | 2D list of rows. Strings starting with '=' become formulas, e.g. '=SUM(B2:B9)'. |
| `cells` | object \| null |  | `None` | Individual cells, e.g. {'B2': 42, 'C2': '=B2*1.15'}. |
| `append` | boolean |  | `False` | Append `values` as new rows after the last used row (ignores start_cell row). |
| `parse_dates` | boolean |  | `True` | Turn ISO strings like '2024-05-01' into real Excel dates. |
| `create` | boolean |  | `True` | Create the file/sheet if missing. |
| `dry_run` | boolean |  | `False` | Preview the change without saving. |

## `insert_delete`

Insert or delete rows/columns. Unlike plain openpyxl, formulas across ALL sheets, named ranges, tables and
merged cells are re-pointed (references into deleted cells become #REF! like Excel).

_read-only: False, destructive: True_

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `path` | string | yes |  | File path, relative to the root folder (or absolute inside it). |

| `index` | integer \| string | yes |  | Row number (1-based) or column letter/number where to insert/delete. |
| `count` | integer |  | `1` | How many rows/columns. |

## `query`

Run SQL across one or MANY spreadsheet files at once (joins, aggregates, window functions, CTEs) with
DuckDB. Read-only SELECT; use `output` to save results to a new file.

_read-only: True, destructive: False_

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `sql` | string | yes |  | One DuckDB SELECT. Tables: files in the root by name (sales.csv -> sales; book.xlsx -> book / book__sheetname), tables= aliases, or FROM 'dir/file.xlsx#Sheet'. |
| `tables` | object \| list[string] \| null |  | `None` | Optional aliases: {'s': 'data/sales.xlsx#2024', 'c': 'crm/customers.csv'}. A list auto-names by file. |
| `folder` | string \| null |  | `None` | Auto-register every file in this folder by name (default: the root). |
| `limit` | integer \| null |  | `None` | Max rows to return (default from server config, usually 100). |
| `offset` | integer |  | `0` | Row offset for paging. |
| `output` | string \| null |  | `None` | Save the FULL result to this file (.xlsx/.csv/.parquet/.json/.md) instead of returning rows. |
| `output_sheet` | string \| null |  | `None` | When output is an existing .xlsx: write into this sheet (replaced if it exists), keeping other sheets. |
| `format` | `json` / `records` / `markdown` |  | `'json'` | json = rows as arrays, records = list of objects, markdown = a table. |

## `formulas`

_read-only: True, destructive: False_

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `path` | string | yes |  | File path, relative to the root folder (or absolute inside it). |
| `action` | `list` / `errors` / `trace` / `evaluate` / `stats` |  | `'list'` | list all formulas \| errors: find #REF!/#DIV/0!/#N/A/circular \| trace a cell's precedents & dependents \| evaluate a cell/range or an ad-hoc formula \| stats: functions used |
| `sheet` | string \| null |  | `None` | Sheet name (or 0-based index). Default: first sheet. |
| `cell` | string \| null |  | `None` | Cell or range for trace/evaluate, e.g. 'D10' or 'Summary!B2'. |

| `limit` | integer \| null |  | `None` | Max rows to return (default from server config, usually 100). |

# Resources

* `sheet://info`: SheetMCP configuration and tips.
* `sheet://files`: All spreadsheet/data files under the allowed root(s).
* `sheet://describe/{path}`: Structure + schema of a file. URL-encode '/' in the path as %2F.
* `sheet://preview/{path}/{sheet}`: First rows of a sheet as a markdown table. URL-encode '/' in path as %2F.
* `sheet://describe/<file>`: one concrete resource per file found at startup (first 100)

# Prompts

* **analyze_spreadsheet**(`path`, `question`?): Explore a spreadsheet and summarise what it contains and what stands out.
* **clean_data**(`path`, `output`?): Find and fix data quality problems, saving a cleaned copy.
* **audit_formulas**(`path`): Audit an Excel model's formulas for errors and risks.
* **compare_files**(`file_a`, `file_b`, `key`?): Explain the differences between two versions of a file.
* **build_report**(`source`, `output`?, `goal`?): Turn raw data into a formatted Excel report with a summary and chart.
